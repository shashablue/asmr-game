# 🎧 おやすみASMRブレンド (Oyasumi ASMR Blend)

みんなでリアルタイムに癒やしの音空間を調合し、そのまま寝落ちできるWebミニゲーム＆ASMRミキサーです。

👉 **今すぐ遊ぶ（デモページ）:** https://shashablue.github.io/asmr-game/

---

## ✨ アプリの特徴・主な機能

### 1. 👥 みんなでセッション（最大10人・リアルタイム協力）
* **4桁コードですぐ合流:** 面倒なアカウント登録は不要。ルーム作成時に発行される数字4桁を共有するだけで最大10人まで同時接続できます。
* **役割分担による心地よい音作り:**
  * 🌊 **環境ベース担当（最大2枠・先着入れ替え制）:** たき火・波音・キーボード打鍵音などの環境音をクロスフェードで滑らかにループ再生します。
  * 💧 **アクセント単発担当:** 鈴・振り子時計・水滴などの単発音を鳴らします。連打による騒がしさを防ぐ「3秒間の余韻クールタイム」付きです。
* **タイムライン（間）の自動記録:** セッション中に参加者がどのタイミングで単発音を鳴らしたかをミリ秒単位で自動記録し、終了後にそのままループ再生できます。

### 2. 🌙 1人でおやすみモード（自分専用ミキサー）
* **全42種のサウンド:** 環境ベース音（8種）＋アクセント単発音（42種・環境音の単発再生含む）を自由に組み合わせて試聴・調合できます。
* **ループ周期の選択:** 30秒 / 60秒 / 90秒 / 120秒 から好みの周期を選んで自分だけの単発リズムを作成できます。
* **おやすみタイマー:** 15分 / 30分 / 60分後に最後の1分かけてゆっくり音量をフェードアウトし、自動停止します。

### 3. ⭐ レシピ保存・カスタマイズ（最大30件）
* 作成した環境ベース音（音量バランス含む）と単発リズムのセットをブラウザ内（`localStorage`）に最大30件まで保存可能。
* 保存前の確認・調整モーダルで、途中でOFFにしたベース音の復元や不要な単発音の除外、後からいつでも名称変更ができます。

## 🛠 技術スタック・工夫した点

* **フロントエンド:** HTML5 / CSS3 / Vanilla JavaScript（ビルド不要・単一HTML構成）
* **Web Audio API:**
  * 継ぎ目のないクロスフェード・ループ再生の実装
  * 長尺環境音を単発再生する際の自動フェードアウト処理
  * 急な大音量を防ぐマスターゲイン制限とおやすみタイマーのスムーズな減衰処理
* **PeerJS (WebRTC):** ブラウザ同士のP2P通信を採用し、専用バックエンドサーバー不要（維持費0円）でリアルタイム同期を実現。
* **ホスティング:** GitHub Pages による完全無料公開。
